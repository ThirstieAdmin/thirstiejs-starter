# Thirstie SDK Examples

These examples assume specific products exist.  You can update the hard coded `product-line-id` to match your applications products.

For example in `examples/demo-01/pdpdemo.html`, you can update `<th-pdp-commerce product-line-id="1042215">` to reference your product.

Alternatively, contact your Thirstie representative for credentials to a demo app to use the existing examples.


To use the examples provided in the `/examples` directory, you can create a file called `.env.examples` in the root directory of your project with credentials for the application you want to use for the examples. Then use the npm script for the selected demo, for example:

```
npm run demo-01
```
